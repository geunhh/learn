규칙

- 한 주제 = 한 파일. 외부 의존은 Google Fonts까지만, CSS·JS는 파일 안에 둔다.
- 실제 겪은 기록(날짜, SHA, 소요 시간)을 근거로 쓴다. 추측은 적지 않는다.
- 공개 저장소다. AWS 계정 ID, ARN, CloudFront 배포 ID, 비밀값은 적지 않는다. 리소스 이름까지만 쓴다.
